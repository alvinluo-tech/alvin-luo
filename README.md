## 02 / Core Highlights

### [01] Canvas X-Ray 动态人像透视 (Hero Stage)
* **基于真实 Alpha 通道的掩码合成**：直接读取训练照的高清不透明像素，无需几何图形模拟身形。光标扫过身体（胸、肩、腹、腰）时实时渲染羽化透镜，展现自律健魄。
* **状态联动与容差处理**：底部状态在 `BUILDING FOR THE WEB` 与 `BUILDING MYSELF` 之间平滑切换；内置面部自适应排除区与轮廓外扩缓冲防断触。
* **跨设备体验**：移动触屏端自动降级为点击/触控反馈策略，兼顾性能与探索趣味。

### [02] Editorial & Brutalist 杂志排版系统
* **视觉语言**：致敬 F1 车手 **Lando Norris** 官网与现代独立出版物风格。
* **三元色设计基调**：米白纸面（`--paper: #f8f8f3`）、浓重墨色（`--ink: #101400`）与高对比荧光绿（`--lime: #d2ff00`），辅以极微弱的 SVG 纸张噪点纹理。
* **破格版式排版**：本地自托管 GitHub 开源字体 `Mona Sans`，结合实心文字与描边轮廓的滚动视差，塑造鲜明的视觉重量。

### [03] Bento Grid 模块化生活切面
* **多源容灾 GitHub 贡献图**：按顺序轮询 `ghchart` / `activity-graph` / `readme-stats`，遇阻自动降级为备用图源与跳转引导，保障全球可达。
* **硬核三大项指标**：卧推 100KG · 深蹲 140KG · 硬拉 180KG，具象化展示工程师的体能自律。
* **生活切面集成**：集成 Currently 近况追踪、随身音乐状态卡片与 CSS 3D 书架，让主页保持活态。

### [04] 钉住式横向旅行胶片 (Travel Section)
* **1:1 视口横移映射**：桌面端结合视口钉住（Pinned Scroll）驱动胶片横移，超长内容平滑滑过；移动端自动解绑并退化为原生横向滚动条。
* **交互式世界地图归档**：`/travel` 独立页由 D3 投影 + TopoJSON 矢量世界地图驱动，支持 1x–6x 缩放平移、双击聚焦与足迹脉冲点。

### [05] 房间即导航 (The Room)
* `/room` 是一个手绘等距（isometric）SVG 房间，坐标由纯函数 `lib/iso.ts` 在运行时生成。
* 每件家具都是一扇门：书桌通向项目、书架通向书单、唱片机通向正在听的歌、窗户跟随杜伦真实时间明暗，点一下猫会打呼噜。

### [06] 年度报告与内容管道 (Year in Review)
* `/year` 以 Scroll-Snap 翻卡形式聚合**真实数据**：构建期聚合站内博客与旅行足迹，客户端补齐 GitHub 与网易云实时源。
* 构建期把 `content/blog/*.md` 编译为静态 HTML，自动生成阅读时长、标题锚点与目录（TOC）、代码高亮、`/rss.xml` 全文订阅源与 `/sitemap.xml`。

### [07] Zero-Bloat 原生纯 CSS 架构
* **零运行时开销**：摒弃重型 UI 库与 Tailwind 依赖，全站依托现代 CSS 变量、Clamp 响应式计算与微动效实现，体积轻量，首屏瞬开。
* **Lenis 惯性物理平滑滚动**：提供丝滑跟手的页面滑动体验，自动遵循 `prefers-reduced-motion` 无障碍降级规范。
* **轻量双语与防闪主题**：
  * 支持 **EN / ZH** 双语即时切换，无集中语言包加载开销。
  * 内联自执行脚本预解析偏好，彻底消除深浅色切换时的白屏闪烁。
* **极客命令面板**：全局监听 `⌘K` / `Ctrl+K`，支持页面级与锚点级的快速模糊跳转。
* **可选微音效**：导航右侧 ♪ 开关（默认静音），开启后主题切换 / 命令面板会有机械咔哒声。

## 03 / Tech Stack

| 领域 | 技术选型 | 作用与考量 |
| :--- | :--- | :--- |
| **应用底座** | [Next.js 16.3 (App Router)](https://nextjs.org/) + [React 19.2](https://react.dev/) | 现代全栈架构，原生支持 Turbopack 极速热重载 |
| **类型规范** | [TypeScript 7](https://www.typescriptlang.org/) | 严苛类型定义（`strict: true`），数据源与组件 Props 全面类型安全 |
| **样式工程** | **Vanilla CSS** (CSS Variables) | 纯原生设计系统，无任何外部 CSS 编译与运行时损耗 |
| **西文字体** | [Mona Sans](https://github.com/github/mona-sans) | 由 `next/font/google` 在构建时自托管，无外部请求，零布局抖动 (CLS) |
| **动效引擎** | [Lenis 1.3](https://github.com/darkroomengineering/lenis) | 高性能惯性平滑滚动底座 |
| **内容解析** | [gray-matter](https://github.com/jonschlinkert/gray-matter) + [marked 18](https://github.com/markedjs/marked) + [highlight.js](https://highlightjs.org/) | 构建期离线静态编译 Markdown 文章至 HTML（含代码高亮与 TOC 抽取） |
| **地理可视化** | [d3-geo](https://github.com/d3/d3-geo) / [d3-zoom](https://github.com/d3/d3-zoom) / [topojson-client](https://github.com/topojson/topojson-client) / [world-atlas](https://github.com/topojson/world-atlas) | 旅行足迹矢量投影地图与缩放平移交互 |
| **交付形态** | **双模式**：标准服务端构建（默认）/ 纯静态导出（`BUILD_STATIC=1`） | 详见 [§8 Deployment](#08--deployment) |

> **注**：本项目**不使用** Tailwind、UI 组件库、`next/image` 或 CSS-in-JS。新增样式请写入 `app/globals.css` 或组件同级的 `.css` 文件。

## 05 / Getting Started

### Prerequisites

| 依赖 | 版本要求 | 说明 |
| :--- | :--- | :--- |
| **Node.js** | `>= 20.9.0` | Next.js 16 的硬性要求（CI 使用 Node 22） |
| **包管理器** | npm（锁定） | 仓库含 `package-lock.json`，CI 使用 `npm ci` |

```bash
# 检查你的版本
node -v   # 应输出 v20.9.0 或更高
```

### 1. Clone

```bash
git clone https://github.com/alvinluo-tech/alvin-luo.git
cd alvin-luo
```

### 2. Install

```bash
npm install
```

### 3. Configure environment variables (optional)

环境变量**仅在启用网易云音乐功能时需要**。缺失时音乐相关组件会整体自动隐藏，站点其余部分完全正常。

```bash
cp .env.example .env.local
```

然后填写 `.env.local`：

```dotenv
NETEASE_API_BASE=https://your-netease-api.vercel.app   # 末尾不带斜杠
NETEASE_API_KEY=your_server_side_api_key
```

> ⚠️ `.gitignore` 中的 `.env*` 规则会同时忽略 `.env.example` 本身。若你 fork 后希望提交自己的模板，请先执行
> `git add -f .env.example`，或在 `.gitignore` 中补一行 `!.env.example`。

### 4. Run the dev server

```bash
npm run dev
```

浏览器打开 [http://localhost:3000](http://localhost:3000) 即可实时预览并支持热重载。

### 5. Build

项目支持两种构建模式，**默认是服务端构建**：

```bash
# A. 服务端构建（默认）→ 产物在 .next/
#    保留 /api/now-playing 代理路由，部署到 Vercel / Node 主机
npm run build

# B. 纯静态导出 → 产物在 out/
#    无服务端运行时，没有 /api 代理，音乐瓷砖走优雅降级
BUILD_STATIC=1 npm run build
```

Windows PowerShell 下等价的静态构建写法：

```powershell
$env:BUILD_STATIC="1"; npm run build
```

### Available Scripts

| 命令 | 作用 |
| :--- | :--- |
| `npm run dev` | 启动开发服务器（Turbopack 热重载） |
| `npm run build` | 生产构建（行为受 `BUILD_STATIC` 影响） |
| `npm run start` | 启动生产服务器（**仅服务端构建可用**，静态导出无需此步） |

> 仓库目前**没有** `lint` / `test` / `format` 脚本。改动前请确保 `npx tsc --noEmit` 通过。

## 06 / Configuration

要把本项目个性化为自己的站点，主要维护以下文件：

| 模块 | 文件位置 | 配置说明 |
| :--- | :--- | :--- |
| **站点元数据** | [`config/site.ts`](config/site.ts) | `SITE_URL`、`GITHUB_USER`、`EMAIL`、`REPORT_YEAR`、`LIVE_STATUS`（城市/时区） |
| **精选项目** | [`data/projects.ts`](data/projects.ts) | `PROJECTS` 数组：标题、描述（含中文）、标签、链接、截图与架构链路 |
| **旅行足迹** | [`data/trips.ts`](data/trips.ts) | `TRIPS` 数组：国家、城市、日期、短评、经纬度、是否上首页 |
| **书架** | [`data/books.ts`](data/books.ts) | `BOOKS` 数组：书名、书脊配色、批注、推荐指数 |
| **人像素材** | [`public/photos/`](public/photos/) | 放入 `hero-clothed.webp` 与 `hero-training.webp`（**需带 Alpha 透明通道**） |
| **透镜调参** | [`components/HeroStage.tsx`](components/HeroStage.tsx) | 调整顶部 `CONFIG`：透镜半径、平滑系数、面部排除区等 |
| **技术随笔** | [`content/blog/`](content/blog/) | 放置 `.md` 文件（见 [§7.1](#71-add-a-blog-post)），自动生成页面与 RSS |
| **设计系统** | [`app/globals.css`](app/globals.css) | 顶部 `:root` 调整纸面底色、墨色对比度与荧光绿强调色 |
| **年度报告** | [`config/site.ts`](config/site.ts) | `REPORT_YEAR` 同时驱动 `/year` 页、OG 海报与终端命令 |
| **访问统计** | [`app/layout.tsx`](app/layout.tsx) | 替换或移除 Umami `data-website-id`，否则统计会记到原作者账号 |

### Environment Variables

| 变量 | 作用域 | 说明 |
| :--- | :--- | :--- |
| `NETEASE_API_BASE` | **仅服务端** | 上游 netease-api 部署地址（不带末尾斜杠） |
| `NETEASE_API_KEY` | **仅服务端** | 与上游项目一致的 `API_KEY` |
| `BUILD_STATIC` | 构建期 | 设为 `1` 时启用纯静态导出到 `out/` |
| `NEXT_PUBLIC_BASE_PATH` | 构建期 | 子路径部署前缀，如 `/alvin-luo`（自定义域名留空） |

### Security Notes

* **密钥必须留在服务端。** `NETEASE_API_KEY` 只允许在 [`app/api/now-playing/route.ts`](app/api/now-playing/route.ts) 这类服务端模块中读取。任何被 `"use client"` 引入的模块里出现的密钥字面量都会被 Next.js **内联进浏览器 bundle**，等同于公开泄露。
* `config/site.ts` 应只存放可公开的站点元数据。若你在此处填写了 `NETEASE_API`，请确认其中不含真实密钥，或改用服务端代理方案。
* 若密钥曾进入 git 历史，仅删除文件是无效的——必须在服务商侧**轮换（rotate）密钥**。

### Image Conventions

全站图片**统一使用 WebP**（`public/` 下已无 PNG / JPEG）。新增图片请遵循：

| 位置 | 建议规格 | 说明 |
| :--- | :--- | :--- |
| `public/photos/` | 1024×1536，**必须保留 Alpha** | Hero 透视依赖 alpha 通道做命中判定，不可压成不透明图 |
| `public/blog/<slug>/` | 长边 ≤ 1600px，q≈82 | 正文显示宽度约 700px，1600px 足够 2× 视网膜屏 |
| `public/travel/` | 长边 ≤ 1600px，q≈82 | 文件名必须是 `<编号>.webp`，并在 `AVAILABLE_PHOTOS` 中登记 |
| `public/projects/` | 1280×800，q≈85 | 与作品集卡片比例一致，避免裁切 |

两个约定：

* **正文图片无需手写尺寸。** `lib/blog.ts` 会在构建期读取图片文件头，自动为 `<img>` 注入 `width` / `height`，浏览器据此提前占位消除 CLS。你只管写 Markdown。
* **不要用 `next/image`。** 项目为静态导出，`next.config.mjs` 中 `images.unoptimized: true`，图片优化需在**提交前**离线完成。

<details>
<summary><b>▸ 批量转换命令（需要 ImageMagick 或 sharp）</b></summary>

```bash
# ImageMagick：转 WebP 并限制长边
magick input.jpg -resize "1600x1600>" -quality 82 output.webp

# 保留 alpha 的 Hero 人像（不要加 -background，否则透明区会被填白）
magick hero-clothed.png -quality 88 hero-clothed.webp
```

> 转换后记得同步更新引用：正文 Markdown 里的路径、`data/projects.ts` 的 `image`、
> `data/trips.ts` 的 `img` 编号。旅行照片的扩展名由 `Travel.tsx` / `TravelArchive.tsx` /
> `WorldMap.tsx` / `YearReport.tsx` 硬编码拼接，改名时这几处需一并确认。
</details>

## 07 / Usage Examples

### 7.1 Add a blog post

在 `content/blog/` 下新建 Markdown 文件。

> ⚠️ **重要约定**：`lib/blog.ts` 通过 `${slug}.md` 定位正文文件，因此**文件名必须与 frontmatter 中的 `slug` 完全一致**，否则文章会出现在列表里但详情页 404。

```markdown
---
slug: "my-new-post"          # 必填，且必须等于文件名（my-new-post.md）
title: "文章标题"             # 必填
date: "2026-09-21"           # 必填，YYYY-MM-DD，用于排序与 RSS
updated: "2026-09-22"        # 可选，缺省回退为 date
category: "projects"         # 必填：projects | life | course
tags: ["Next.js", "复盘"]     # 可选，参与搜索与筛选
summary: "一句话摘要"          # 可选，用于列表与 RSS description
pinned: true                 # 可选，置顶到列表最前
source: "https://..."        # 可选，原文外链
---

# 正文标题

正文以标准 Markdown 书写。

## 二级标题会自动进入目录
```

**正文配图**：图片放入 `public/blog/<slug>/`，正文用绝对路径引用。构建时会自动补上 `basePath` 并注入懒加载属性。

```markdown
![截图](/blog/my-new-post/screenshot.webp)
```

> 正文开头的第一个 `# H1` 会被自动剥离（避免与页面标题重复），直接从二级标题开始写即可。

**可用的分类**（定义于 `lib/blog.ts` 的 `CATEGORY_LABELS`）：`projects` / `life` / `course`。

文章会自动获得：阅读时长估算（中文 400 字/分钟、英文 200 词/分钟）、标题锚点、目录、代码高亮、图片灯箱、代码复制按钮、RSS 收录与 sitemap 收录。

### 7.2 Add a project

编辑 [`data/projects.ts`](data/projects.ts)，向 `PROJECTS` 追加一项：

```typescript
{

  title: "My Project",

  demo: "https://demo.example.com",

}
```

### 7.3 Add a travel stop

编辑 [`data/trips.ts`](data/trips.ts)。**照片登记是必需步骤**——未登记的图片会渲染为占位卡而非 404：

```typescript
// 1) 把照片放到 public/travel/39.webp
// 2) 在 AVAILABLE_PHOTOS 中登记编号，避免浏览器 404
export const AVAILABLE_PHOTOS = new Set<string>(["05", "39"]);

// 3) 追加足迹
{

  country: "中国",
  countryEn: "China",
  place: "成都",
  date: "2026-08-12",
  note: "一句话感受",
  coord: [104.07, 30.67],       // [经度, 纬度] —— 归档页地图脉冲点
  featured: true,               // 是否上首页胶片
}
```

### 7.4 Tune the X-Ray lens

[`components/HeroStage.tsx`](components/HeroStage.tsx) 顶部的 `CONFIG` 常量控制 Canvas 透镜物理手感：

```typescript
const CONFIG = {
  lensR: 0.18,        // 透镜相对图片宽度的半径（数值越大，透视圈越大）
  lensMinPx: 70,      // 透镜最小绝对像素半径（防止在小屏过小）
  posEase: 0.16,      // 透镜跟随光标的阻尼缓动（越小越柔软，越大越即时）
  intensityEase: 0.1, // 透镜显隐淡入淡出速度
  bodyDilate: 16,     // 轮廓外扩像素（离开身体边缘后的容差缓冲，防闪烁）
  face: {             // 面部排除椭圆区（归一化坐标），悬停脸部自动隐退透视
    cx: 0.5, cy: 0.185, rx: 0.115, ry: 0.125
  },
};
```

## 08 / Deployment

### 方案 A：Vercel 部署（推荐 · 服务端模式）

保留 `/api/now-playing` 服务端代理，音乐功能完整可用。

1. 将仓库推送到 GitHub。
2. 登录 [Vercel](https://vercel.com/new) 点击 **Import** 导入该仓库。
3. Framework Preset 选择 **Next.js**。
4. 在 **Settings → Environment Variables** 中配置 `NETEASE_API_BASE` 与 `NETEASE_API_KEY`（**不要**设置 `BUILD_STATIC`）。
5. 点击 **Deploy**。此后每次推送到 `main` 自动构建发布。

### 方案 B：GitHub Pages 部署（静态模式）

仓库已包含自动化工作流 [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml)：

1. 进入 GitHub 仓库 **Settings → Pages**。
2. 在 **Build and deployment → Source** 中选择 **GitHub Actions**。
3. 推送到 `main` 即触发构建（工作流已自动注入 `BUILD_STATIC=1`）。

**basePath 是自动推断的**，无需手动设置环境变量：

| 仓库形态 | 站点地址 | basePath |
| :--- | :--- | :--- |
| 仓库名形如 `*.github.io` | `https://<user>.github.io/` | 留空 |
| 仓库根含 `CNAME` 文件（本仓库即是） | `https://alvin-luo.me/` | 留空 |
| 普通项目仓库（如 `personal-website`） | `https://<user>.github.io/<repo>/` | `/<repo>` |

若需**本地手动**复现静态构建：

```bash
BUILD_STATIC=1 NEXT_PUBLIC_BASE_PATH=/<仓库名> npm run build
```

> **静态模式的取舍**：没有服务端运行时，`/api/now-playing` 不存在，NOW PLAYING / 音乐瓷砖会优雅降级隐藏。GitHub 贡献图与年度报告中的 GitHub / 音乐数据仍可正常获取（客户端直连公共 API）。

<details>
<summary><b>▸ 深入查看：Nginx 独立私有服务器静态配置参考</b></summary>

若使用自有 VPS 或 Nginx 托管静态产物 `out/`：

```nginx
server {
    listen 80;
    server_name yourdomain.com;
    root /var/www/personal-website/out;
    index index.html;

    location / {
        try_files $uri $uri.html $uri/ /index.html;
    }

    # 静态资产长效缓存
    location /_next/static/ {
        expires 1y;
        add_header Cache-Control "public, max-age=31536000, immutable";
    }
}
```
</details>

## 09 / Troubleshooting

| 现象 | 原因与解法 |
| :--- | :--- |
| `npm run build` 报 Node 版本错误 | Next.js 16 要求 Node `>= 20.9.0`，请升级 Node（`node -v` 确认） |
| 音乐瓷砖 / NOW PLAYING 整块消失 | 未配置 `NETEASE_API_BASE` + `NETEASE_API_KEY`，或使用了 `BUILD_STATIC=1`（静态模式无 `/api` 代理）。这是**预期降级**，非 bug |
| 文章出现在列表，但点进去 404 | 文件名与 frontmatter 的 `slug` 不一致。`lib/blog.ts` 按 `${slug}.md` 读取正文 |
| 旅行照片显示为占位卡 | 照片编号未登记进 `data/trips.ts` 的 `AVAILABLE_PHOTOS`，或文件不在 `public/travel/<img>.webp` |
| 文章配图在子路径部署后 404 | 正文必须使用 `/blog/<slug>/x.webp` 形式（构建时自动注入 basePath） |
| GitHub 热力图显示兜底图源 | GitHub 未认证公共 API 限流（60 次/时/IP），卡片会自动切换备用图源 |
| 页面出现白屏闪烁（深色模式） | 防闪脚本在 `app/layout.tsx` 以 `beforeInteractive` 注入，请勿改为普通 `<script>` |
| 动画在低配设备卡顿 | 全站遵循 `prefers-reduced-motion`；可在系统设置中开启「减少动态效果」验证降级路径 |

## 10 / Contributing

这是一个个人站点项目，但 issue 与 PR 都欢迎——尤其是无障碍、性能与文档改进。

### Before you start

* **先开 issue 讨论**再动手改大功能，避免做完了发现方向不一致。
* 本项目的设计语言是刻意为之的（原生 CSS、零 UI 库、编辑风格排版）。提交 UI 改动前请先确认它符合 [§2 的核心设计原则](#02--core-highlights)。
* 不接受引入 Tailwind、UI 组件库、`next/image` 或 CSS-in-JS 的 PR。

### Workflow

```bash
# 1. Fork 并克隆
git clone https://github.com/<you>/alvin-luo.git && cd alvin-luo

# 2. 建立分支（请使用语义化前缀）
git checkout -b feat/lens-falloff-curve
# 前缀约定：feat/ · fix/ · docs/ · refactor/ · perf/ · chore/

# 3. 安装依赖并开发
npm install && npm run dev

# 4. 提交前自检
npx tsc --noEmit          # 类型必须零错误
npm run build             # 服务端构建必须通过
BUILD_STATIC=1 npm run build   # 静态构建也必须通过（涉及构建配置时）
```

### Commit messages

遵循 [Conventional Commits](https://www.conventionalcommits.org/)，与现有历史保持一致：

```text
fix: resolve travel duplicate keys, CLS loading style, missing CSS tokens
feat(room): add vinyl interaction on the turntable
docs: correct build mode section in README
```

### Pull request checklist

- [ ] `npx tsc --noEmit` 通过
- [ ] 两种构建模式均通过（改动涉及 `next.config.mjs` / 环境变量时）
- [ ] 新增文案已同时提供 EN / ZH 两份（使用 `<T en="…" zh="…" />`）
- [ ] 新增动效遵循 `prefers-reduced-motion` 降级
- [ ] 未提交任何密钥或 `.env.local`
- [ ] 未引入新的运行时依赖（如确有必要，请在 PR 描述中说明取舍）

### Reporting bugs

请在 issue 中附上：复现步骤、期望行为、实际行为、浏览器与 Node 版本、以及相关截图（若涉及视觉问题）。

## 11 / Design Principles

> *"Good design is as little design as possible, but with personality that cuts through the noise."*

1. **多维真实的工程师特质**：代码不是程序员唯一的表达载体。将技术构建、体能自律、旅行足迹与深度思考有机结合，传递更加立体立体的个人形象。
2. **克制而有张力的交互**：拒绝千篇一律的模板大头照，通过物理探索感的 Canvas Alpha 透视，在首屏第一秒建立探索欲与高级感。
3. **内容导向的阅读沉浸**：精调字重、行距与版芯宽度，使长篇复盘或短篇技术随笔均具备杂志级的静谧阅读质感。
